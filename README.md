# DailyReport

A Python desktop application for generating daily attendance reports from ZKTeco attendance data.

## Overview

DailyReport was built to turn raw attendance records into a practical daily report for a workplace environment.

The application can:

- Read attendance data exported from ZKTeco Attendance Management.
- Process employee attendance records.
- Compare attendance data with mission/leave information.
- Distinguish between employees with one attendance record and employees with both arrival and departure records.
- Generate a clear daily report for around 150 employees.

## Technology

- Python
- Tkinter
- Excel data processing
- Desktop automation
- Git / GitHub

## Why I built it

This project started from a real operational problem and was built as a practical tool rather than a tutorial project. The goal was to reduce repetitive manual work and make the daily attendance process faster and easier to manage.
